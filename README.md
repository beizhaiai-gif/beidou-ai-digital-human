# 北抖 AI 数字人 · 桌面客户端

抖音竖屏数字人口播视频的**本地量产工具**。从一条原片出发，自动完成文案、配音、数字人、字幕、分镜剪辑，最后在本机渲染出成片。

> 这是一个客户端程序，不是网页。下载安装后双击打开即可使用。

---

## 下载

前往 **[Releases](../../releases/latest)** 页面下载。

| 系统 | 文件 | 状态 |
|---|---|---|
| Mac（Intel 芯片） | `BeidouAI-DigitalHuman-0.1.0-mac-x64.zip` | ✅ 可用 |
| Mac（Apple 芯片 M1–M4） | — | ⏳ 运行环境包需在 M 系列机器上生成 |
| Windows 64 位 | — | ⏳ 待适配 |

安装：解压 → 把「北抖AI数字人.app」拖进「应用程序」。

### 第一次打开会提示「无法验证开发者」

因为程序没有购买苹果/微软的签名证书（一年上千元），系统会拦一下。**这不影响使用**：

- **Mac**：在「应用程序」里**右键点击**图标 → 选「打开」→ 弹窗里再点「打开」。之后就可以正常双击了。
  - 如果提示「已损坏，无法打开」，打开「终端」执行一次：
    ```
    xattr -cr /Applications/北抖AI数字人.app
    ```

## 首次启动会下载运行环境

数字人的语音识别、口型对齐、视频渲染需要一套本地运行环境（约 1.6GB），**没有放进安装包**，第一次启动时自动下载到你的电脑里：

| 组件 | 用途 | 大小 |
|---|---|---|
| FFmpeg | 音视频处理 | ~51MB |
| Python 运行环境 | 字级时间戳识别 | ~257MB |
| 数字人引擎（含 Remotion） | 视频渲染 | ~240MB |
| 语音识别模型 | 中文口型对齐 | ~496MB |

- 全程有进度条，下载一次就好，之后不再重复下载
- 存放位置：Mac 在 `~/Library/Application Support/北抖AI数字人/runtime`，Windows 在 `%APPDATA%\北抖AI数字人\runtime`
- 建议在网络稳定的环境下首次启动；中途断了重启应用会**接着下**已完成的组件

## 主要功能

- **原片直读**：直接选本机视频文件，不上传、不等待
- **文案生成**：基于原片内容生成口播文案，可编辑
- **数字人视频**：按文案生成数字人口播片段
- **智能剪辑**：自动分镜成片（51 镜级别的镜头编排），字幕按配音时间轴对齐
- **分镜可干预**：成片后可以单独改某一镜的卡片样式或文案，只重渲那一镜，不动其它时间轴

---

## 关于密钥

客户端**不含任何第三方服务的密钥**。所有需要密钥的能力（文案模型、数字人合成、语音识别）都通过服务端代理转发，密钥保存在服务端，不会下发到你的电脑上。
